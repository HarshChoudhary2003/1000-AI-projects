- `notebook.ipynb`: Interactive Jupyter Notebook ready for local execution or Google Colab

- `requirements.txt`: Curated pip dependencies tailored to the project

## 🚀 Global Quickstart

To run any project:
1. Navigate into the target project folder:
   ```bash
   cd "01_Machine_Learning_Basic_Projects/PROJECT_0001_linear_regression_model_for_predicting_house_prices"
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the implementation:
   ```bash
   python main.py
   ```
