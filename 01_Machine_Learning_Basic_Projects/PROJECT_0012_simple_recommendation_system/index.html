💡 Mathematical Formula

Similarity is computed via the normalized dot product of two user rating vectors:

cos(θ) = (A · B) / (||A|| × ||B||)

When vectors point in the same direction in 5D movie space, cosine approaches 1.0. Unwatched movies (0 rating) are filtered, and the closest peer's favorites are surfaced.
