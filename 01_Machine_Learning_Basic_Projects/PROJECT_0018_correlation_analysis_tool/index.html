Multicollinearity Diagnosis

When features like Metric_A and Metric_B have near-perfect correlation ($r \approx 0.99$), they introduce severe **redundancy** in downstream machine learning models (causing unstable coefficient weights and inflated standard errors).

Pearson vs Spearman:
Pearson measures strict linear affinity; Spearman measures monotonic rank agreement.
Recommended Action:
Drop one redundant variable or apply PCA dimensionality reduction.
