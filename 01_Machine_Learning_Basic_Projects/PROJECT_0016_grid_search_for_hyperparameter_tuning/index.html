Why C & Kernel Matter in SVM

C: Balances decision boundary margin width vs misclassification penalty. Large C aims for fewer training errors (risk of overfitting), while small C favors smoother margins.
Kernel: Maps non-linear feature interactions into higher-dimensional Hilbert spaces where a linear hyperplane can separate the classes.
